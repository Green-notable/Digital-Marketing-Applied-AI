# Café Library | Warwick Campus Café Website
Digital Marketing Applied AI Course Project

## 📌 Project Overview
This is a single-page static HTML website built for Café Library, a campus café at the University of Warwick.
The project demonstrates core digital marketing practices: on-page SEO, local business structured data (Schema.org), responsive web design, and search engine optimisation for local search.

## ✨ Key Features
- Responsive layout, compatible with mobile & desktop
- Complete on-page SEO setup: title, meta description, keywords, canonical link
- JSON-LD structured data for local business, supporting Google local search display
- Clean static HTML, no extra framework dependencies
- Optimised for local search targeting keyword: `Warwick campus café`
